دليل نظام ERP الموديلر الذكي

حل واحد متكامل لعدة احتياجات - منصة Flutter المتعددة

نظرة عامة على النظام

نظام الـ ERP الخاص بنا مصمم بأسلوب Modular Architecture، مما يعني أنه تطبيق واحد يمكن تهيئته ليعمل في أشكال مختلفة حسب احتياج العميل. نستخدم تقنية Flutter Flavors لتقديم نسخ مخصصة لكل فئة من العملاء بأقل مجهود وبأعلى كفاءة في الصيانة.

أهم المميزات والخصائص

تعدد الواجهات (Flavors)

إمكانية تشغيل التطبيق بنظام المناديب، أو الحسابات، أو الموظفين، أو نظام كامل بضغطة زر واحدة.

تخصيص كامل (Theming)

كل flavor له ألوانه الخاصة، شعاره، ومساراته التي تختلف ديناميكياً حسب الـ Configuration.

كود موحد (Core Logic)

جميع العمليات الأساسية مشتركة، مما يسهل تحديث النظام بالكامل دون تكرار الأخطاء.

دعم اللغات الكامل

دعم كامل للغة العربية والإنجليزية مع إمكانية التبديل السهل.

العملاء والأنظمة المدعومة

النظام (Flavor) الوصف والهدف المميزات المفتوحة
representatives نظام مخصص لفرق المبيعات والمناديب في الميدان. المناديب، الفواتير، التقارير الميدانية.
accounts نظام محاسبي للشركات الصغيرة والمتوسطة. شجرة الحسابات، المعاملات، كشوفات الحساب.
employees نظام إدارة شؤون الموظفين (HR Lite). الحضور والانصراف، بيانات الموظفين، الرواتب.
full نظام ERP شامل يجمع كل المميزات السابقة. المخازن، المبيعات، الحسابات، الموظفين، الإعدادات.

تشغيل التطبيق (البرمجة)

لتشغيل التطبيق لأي عميل، استخدم الأوامر التالية من الـ Terminal:

تشغيل نظام المناديب:

flutter run --flavor representatives -t lib/main_representatives.dart

تشغيل نظام الحسابات:

flutter run --flavor accounts -t lib/main_accounts.dart

تشغيل نظام الموظفين:

flutter run --flavor employees -t lib/main_employees.dart

تشغيل النظام الكامل:

flutter run --flavor full -t lib/main_full.dart

إصدار النسخ النهائية (APK / AAB)

لإنتاج ملفات جاهزة للعملاء، يمكنك استخدام سكربت الـ Build المخصص أو أوامر فلاتر القياسية:

إصدار APK لنظام المناديب:

flutter build apk --flavor representatives -t lib/main_representatives.dart

إصدار APK لنظام الحسابات:

flutter build apk --flavor accounts -t lib/main_accounts.dart

إصدار AAB (لمتجر Google Play):

flutter build appbundle --flavor full -t lib/main_full.dart
نصيحة: يمكنك استخدام السكربت المبرمج مسبقاً في المشروع: dart run tool/build_flavor.dart --apk-only

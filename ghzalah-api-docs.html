🚀 البداية السريعة

للبدء في استخدام API متجر غزالة، تحتاج إلى إرسال طلبات HTTP إلى الرابط الأساسي. جميع الردود تكون بصيغة JSON.

bash 
# جلب معلومات المتجر الأساسية
curl -X GET https://ghzalah.com/wp-json/

# جلب المنتجات (يتطلب مصادقة)
curl -X GET https://ghzalah.com/wp-json/wc/v3/products \
  -u consumer_key:consumer_secret

# جلب المقالات
curl -X GET https://ghzalah.com/wp-json/wp/v2/posts
javascript 
// جلب المنتجات من WooCommerce API
const baseUrl = 'https://ghzalah.com/wp-json';

// بدون مصادقة - البيانات العامة
const response = await fetch(`${baseUrl}/wp/v2/posts`);
const posts = await response.json();

// مع مصادقة - WooCommerce
const wcResponse = await fetch(
  `${baseUrl}/wc/v3/products`, {
    headers: {
      'Authorization': 'Basic ' + btoa('ck_xxx:cs_xxx')
    }
});
const products = await wcResponse.json();
python 
import requests

base_url = "https://ghzalah.com/wp-json"

# جلب المقالات العامة
response = requests.get(f"{base_url}/wp/v2/posts")
posts = response.json()

# WooCommerce مع مصادقة
wc_response = requests.get(
    f"{base_url}/wc/v3/products",
    auth=("ck_your_key", "cs_your_secret")
)
products = wc_response.json()
php 
<?php
// جلب بيانات من API متجر غزالة
$base_url = 'https://ghzalah.com/wp-json';

// جلب المقالات
$response = file_get_contents("$base_url/wp/v2/posts");
$posts = json_decode($response, true);

// WooCommerce مع مصادقة
$context = stream_context_create([
    'http' => [
        'header' => 'Authorization: Basic ' . base64_encode('ck_xxx:cs_xxx')
    ]
]);
$wc = file_get_contents("$base_url/wc/v3/products", false, $context);
$products = json_decode($wc, true);
?>

🔐 المصادقة (Authentication)

يدعم متجر غزالة عدة طرق للمصادقة. اختر الطريقة المناسبة حسب نوع التطبيق.

🔑 Application Passwords

كلمات مرور التطبيقات - الطريقة الموصى بها لتطبيقات الطرف الثالث.

Authorization: Basic base64(username:app_password)

رابط التفويض:
https://ghzalah.com/wp-admin/authorize-application.php

🛒 WooCommerce Keys

مفاتيح API الخاصة بـ WooCommerce - للعمليات التجارية.

# عبر Query Parameters
?consumer_key=ck_xxx&consumer_secret=cs_xxx

# أو عبر Basic Auth
Authorization: Basic base64(ck_xxx:cs_xxx)

🍪 Cookie Auth

مصادقة الكوكيز - للاستخدام الداخلي مع لوحة التحكم فقط.

X-WP-Nonce: {nonce_value}
Cookie: wordpress_logged_in_xxx=...
